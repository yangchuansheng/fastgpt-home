# 解决FastGPT中HTTP文生图工具调用后图片无法正常展示的问题

## 现象
用户在私有部署版本的FastGPT中，使用自定义的HTTP文生图工具。该工具单独调试时运行正常，但在配置了该工具的Agent（含V2 beat）中调用后，图片生成完成却无法正常展示。该功能在之前的FastGPT版本中可正常使用，近两个版本更新后出现该问题。相关界面截图显示对话界面未加载生成的图片资源。

## 可能原因
目前该问题的具体根因需结合实际部署环境确认，潜在关联方向包括HTTP工具响应内容的格式解析异常、Agent配置的响应规则与工具实际返回不匹配、前端渲染环节的资源加载逻辑异常等。由于未获取到具体的报错日志，无法直接定位核心问题。

## 排查步骤
1.  单独调试自定义HTTP文生图工具，确认接口可以正常返回符合要求的图片资源，包括正确的响应头、图片链接或二进制数据。
2.  对比Agent配置中的HTTP工具参数与单独调试时的参数，检查请求方式、请求头、请求体、响应解析规则是否完全一致，避免出现配置差异导致的解析失败。
3.  查看FastGPT的后端运行日志与前端控制台日志，定位与工具响应解析、图片资源加载相关的异常信息。
4.  检查Agent的对话流程配置，确认图片生成结果是否被正确传递到对话展示环节，未被过滤或截断。

## 解决与验证
根据排查到的具体异常点进行针对性修复，例如调整Agent中HTTP工具的响应解析规则以匹配工具返回的格式，修正配置中的参数传递错误。修复完成后，重新创建包含该文生图工具的Agent并发起对话调用，验证生成的图片是否可以正常在对话界面展示。如果问题仍未解决，需进一步核对FastGPT版本与工具的兼容性，或联系项目维护者提供更详细的日志信息协助排查。
