# 解决FastGPT副本工作流远程调用返回空数组的问题

## 现象
用户在FastGPT中使用工具调用功能调用其他工作流时，为目标工作流创建副本后，副本工作流的内部运行可正常完成。但通过外部服务远程调用该副本工作流时，请求显示成功，却返回空数组[]。源工作流的远程调用功能可正常返回结果，副本工作流的内部调用也可正常运行。

## 可能原因
该问题暂无明确官方定义的触发条件，需结合实际部署环境、工作流配置细节按实际情况排查，常见关联方向包括工作流副本的调用权限配置、API密钥绑定的工作流范围、远程调用的参数传递一致性。

## 排查步骤
1.  检查当前使用的API密钥的授权范围，确认是否覆盖目标副本工作流。
2.  对比源工作流与副本工作流的工具调用配置，核对参数传递、节点设置等内容是否一致。
3.  再次验证副本工作流的内部运行流程，确认内部调用无异常。
4.  记录远程调用副本工作流的完整请求参数，与源工作流的请求参数进行一致性对比。

## 解决与验证
若排查发现API密钥未授权副本工作流，调整API密钥的授权范围，使其覆盖目标副本工作流。若发现工作流配置存在差异，修正副本工作流的工具调用参数，与源工作流保持一致。验证时，使用调整后的配置远程调用副本工作流，确认返回结果不再为空数组，与源工作流的调用结果一致。
