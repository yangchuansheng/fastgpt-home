# FastGPT V4.7.1版本升级与环境变量变更处理指南

## 结论
FastGPT V4.7.1版本更新包含环境变量配置变更与配套升级脚本两项核心内容。该版本升级仅适用于版本低于4.12.0的FastGPT部署，需同步完成配置调整与脚本执行方可完成升级。本次更新的升级脚本用于自动处理版本文件的替换与校验，减少手动操作的失误风险。

## 具体怎么做
1.  确认当前FastGPT部署版本低于4.12.0，该版本升级仅支持该范围内的部署
2.  获取官方提供的V4.7.1版本专属升级脚本
3.  对照官方更新说明，调整所有涉及变更的环境变量配置
4.  执行升级脚本，等待脚本完成版本文件替换与配置校验
5.  重启FastGPT服务，确认版本已更新至V4.7.1

## 注意事项
1.  仅支持版本低于4.12.0的FastGPT部署升级，高于该版本的部署需参考对应版本的升级说明
2.  环境变量变更涉及核心服务配置，任何遗漏或错误都可能导致服务启动失败，需严格按照官方清单执行
3.  升级脚本执行过程中请勿中断操作，否则可能导致部署文件损坏，无法正常启动服务
4.  升级完成后需查看服务运行日志，确认无环境变量加载错误、配置不匹配等报错后，再开放对外访问
