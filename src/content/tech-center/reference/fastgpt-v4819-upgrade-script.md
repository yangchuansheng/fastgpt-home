# FastGPT V4.8.19版本升级脚本的操作使用说明

## 结论
FastGPT V4.8.19版本属于需要使用专属升级脚本完成升级的FastGPT历史版本。执行官方提供的对应升级脚本，即可完成该版本的部署更新操作。

## 具体怎么做
1. 确认当前部署的FastGPT版本符合升级至V4.8.19的目标场景。
2. 访问FastGPT官方自部署升级文档的V4.8.19版本章节，获取专属升级脚本文件。
3. 在部署服务器中运行下载好的升级脚本，完成版本升级操作。

## 注意事项
1. 该升级脚本仅适用于将FastGPT升级至V4.8.19版本的场景。
2. 必须使用官方提供的专属升级脚本完成操作，不可自行修改脚本内容。
3. 升级过程中需确保服务器网络稳定，避免中断脚本执行。
4. 该版本属于FastGPT历史版本中需使用升级脚本的类型。
