# 自部署环境下FastGPT V4.8.11版本升级脚本的具体使用说明

## 结论
FastGPT V4.8.11版本升级需使用官方配套的升级脚本完成。该升级属于FastGPT自部署环境下的轻量型更新，适用于版本低于4.12.0的部署实例，按官方步骤操作即可完成版本切换。

## 具体怎么做
1. 进入FastGPT自部署环境的升级脚本存放目录
2. 定位到V4.8.11对应的升级脚本文件
3. 执行该脚本完成版本升级操作
4. 脚本执行完毕后重启FastGPT相关服务

## 注意事项
1. 该升级脚本仅适用于版本低于4.12.0的FastGPT自部署实例
2. 请勿修改官方提供的升级脚本的原始内容
3. 升级前需完成当前FastGPT系统的数据备份，避免升级过程中出现数据丢失问题
