# FastGPT V4.14.18版本升级操作参考说明

## 结论
本文档提供FastGPT V4.14.18版本的升级参考。该版本属于4.14.x系列升级包，部分前置版本需执行升级脚本或调整环境变量配置。

## 具体怎么做
1. 确认当前运行的FastGPT版本属于4.14.x系列；
2. 若当前版本为V4.14.0、V4.14.1、V4.14.3至V4.14.7、V4.14.5.1等存在升级脚本要求的版本，需执行对应升级脚本；
3. 检查当前版本是否存在环境变量变更，如V4.14.8、V4.14.9、V4.14.10、V4.14.11等版本；
4. 按照官方4.14.x系列升级流程完成部署更新。

## 注意事项
1. 仅适用于4.14.x系列版本升级，不支持跨大版本（如4.13.x及更早）升级；
2. 涉及环境变量变更的版本升级前，需确认对应配置项的调整要求；
3. 升级前需完成数据备份，避免升级过程中出现数据丢失。
