# FastGPT V4.14.2版本升级适配操作说明

## 结论
V4.14.2是FastGPT 4.14.x版本系列的升级项。升级至该版本需结合当前版本的适配要求完成操作，部分前置版本存在额外配置要求。

## 具体怎么做
1. 确认当前部署的FastGPT版本属于4.14.x分支
2. 查阅官方4.14.x系列版本清单，检查当前版本是否标注有环境变量变更，需同步更新对应环境变量配置
3. 若当前版本标注需升级脚本，先执行对应升级脚本后再完成V4.14.2版本升级
4. 避开已被弃用的V4.14.25版本

## 注意事项
1. 该操作仅适用于4.14.x系列版本的升级，不适用于其他版本分支
2. 标注有环境变量变更的版本，升级前必须完成对应环境变量的调整
3. 标注有升级脚本的版本，需先执行专属升级脚本再升级至V4.14.2
4. V4.14.25版本已被官方弃用，请勿选择该版本进行部署或升级
