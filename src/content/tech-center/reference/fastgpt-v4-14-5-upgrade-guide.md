# FastGPT V4.14.5版本环境变量变更及升级操作说明

## 结论
FastGPT V4.14.5版本存在专属的环境变量变更，同时官方提供了对应的升级脚本。该升级流程仅针对4.14.x系列版本，可帮助用户完成该版本的部署更新。

## 具体怎么做
1. 确认当前部署的FastGPT版本属于4.14.x系列，避免误用脚本导致异常。
2. 从官方对应路径获取V4.14.5版本的专属升级脚本，确保版本匹配。
3. 根据本次版本的环境变量变更要求，调整部署配置中的对应环境变量参数。
4. 运行升级脚本执行升级操作，期间请勿中断服务或修改配置。
5. 升级完成后重启相关服务，验证系统运行状态是否正常。

## 注意事项
1. 该升级流程仅适用于FastGPT 4.14.x系列版本，不适用于其他大版本。
2. 环境变量变更后需同步更新所有部署节点的配置，避免出现配置不一致导致的服务启动失败。
3. 运行升级脚本前，建议备份原有数据库配置与业务数据，防止升级过程中出现数据丢失或配置损坏。
4. 若升级过程中出现报错，需优先检查环境变量配置是否符合本次变更要求，再排查其他执行问题。
