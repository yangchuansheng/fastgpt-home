# FastGPT V4.14.20版本升级操作参考指南

## 结论
本页面为FastGPT 4.14.x系列的V4.14.20版本升级提供官方参考说明。升级前需核对当前部署版本与目标版本的变更项，部分前置版本存在环境变量变更或需要执行升级脚本。

## 具体怎么做
1. 进入FastGPT官方文档的自部署-版本升级板块，打开4.14.x分类页面
2. 找到V4.14.20的升级说明页面，查看该版本的更新与前置要求
3. 梳理当前版本到V4.14.20之间的子版本变更，确认环境变量变更、升级脚本等配置要求
4. 按对应版本的规则完成前置操作，如需执行升级脚本则提前配置执行环境
5. 完成前置步骤后执行V4.14.20版本升级

## 注意事项
1. 4.14.x系列多个版本存在环境变量变更，升级前需核对对应版本的配置项
2. 标记有升级脚本的前置版本，需执行脚本后再升级至V4.14.20
3. 请勿跳过中间版本直接升级，需按版本顺序逐步执行
4. 升级过程中需检查配置文件与环境变量的匹配性，避免配置错误
