# FastGPT V4.4.5版本升级脚本使用指南

## 结论
FastGPT V4.4.5版本升级需使用专属升级脚本，该方案仅适用于版本低于4.12.0的自部署FastGPT实例。执行对应版本的升级脚本即可完成版本更新与必要的配置适配工作。

## 具体怎么做
1. 确认当前部署的FastGPT版本低于4.12.0，确认符合升级前提条件。
2. 获取V4.4.5版本对应的专属升级脚本文件。
3. 按照脚本附带的指引完成升级执行操作。

## 注意事项
1. 该升级方案仅支持版本低于4.12.0的FastGPT自部署实例，不适用于更高版本的升级操作。
2. 升级必须使用V4.4.5专属升级脚本，不可混用其他版本的升级脚本。
