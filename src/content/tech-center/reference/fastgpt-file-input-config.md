# FastGPT 4.8.9及以上版本文件输入功能配置使用说明

## 结论
FastGPT 4.8.9及以上版本支持在简易模式与工作流中配置用户上传文件功能。该功能可实现应用内的用户文件上传交互与后续处理，本文将介绍其使用方式与文档解析、多模态文件处理的差异。

## 具体怎么做
1. 进入FastGPT的应用构建模块，打开通用配置页面。
2. 找到文件输入功能配置项，根据应用的实际模式选择启用对应场景的上传功能。

## 注意事项
1. 该功能仅支持FastGPT 4.8.9及以上版本使用。
2. 功能适配范围仅限简易模式与工作流两种应用构建模式。
3. 需明确文档解析与多模态文件处理的不同应用场景。
