# FastGPT V4.8.18与V4.8.20版本更新内容速查

## 结论
本页整理了FastGPT V4.8.18与V4.8.20的官方更新内容，涵盖新增功能、体验优化与问题修复三类，同时包含对应版本的升级脚本说明。

## 具体怎么做
1. 新增功能：
   - 工作流知识库检索支持按知识库权限过滤
   - 飞书/语雀知识库查看原文
   - 新增流程等待插件，可等待n毫秒后继续执行流程
   - 飞书机器人接入，支持配置私有化飞书地址
2. 体验优化：
   - 成员列表分页加载
   - 统一分页加载代码
   - 对话页面加载时可配置是否为独立页面
   - 成员头像迁移至成员表
3. 问题修复：
   - 语雀文件库导入时嵌套文件内容无法展开
   - 工作流编排中LLM参数无法关闭
   - 工作流编排中代码运行节点还原模板
   - HTTP接口适配对象字符串解析
   - 通过API上传文件（localFile）接口图片过期标记未清除
   - 工作流导入编排时number input类型无法覆盖
   - 部分模型提供商logo无法正常显示
4. 升级说明：V4.8.18附带升级脚本，V4.8.20附带升级脚本且存在环境变量变更

## 注意事项
- 升级V4.8.20版本时，需注意存在环境变量变更，需配合对应升级脚本操作
- 工作流相关功能更新后，需校验对应节点配置是否正常生效
- 配置飞书机器人时，需确保私有化飞书地址填写正确
