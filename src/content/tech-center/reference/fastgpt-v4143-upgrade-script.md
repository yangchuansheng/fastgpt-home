# FastGPT V4.14.3版本升级脚本的使用说明

## 结论
FastGPT V4.14.3版本提供专属升级脚本用于完成版本升级。该脚本是将FastGPT系统升级至V4.14.3版本的专用操作工具。

## 具体怎么做
1. 进入FastGPT官方文档中V4.14.3版本升级脚本的专属页面。
2. 按照页面指引获取对应的升级脚本文件。
3. 运行升级脚本，按照提示完成版本升级流程。

## 注意事项
1. 升级前需确认当前运行的FastGPT版本属于4.14.x系列。
2. 若升级路径经过带有环境变量变更的版本，需提前调整对应配置项。
3. 升级过程中请勿中断脚本执行，避免引发系统异常。
