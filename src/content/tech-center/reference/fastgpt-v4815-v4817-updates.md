# FastGPT V4.8.15与V4.8.17版本更新内容速查

## 结论
本页整理FastGPT V4.8.15与V4.8.17版本的官方更新内容，涵盖新增功能、体验优化与问题修复三类。用户可根据升级需求对照对应内容完成适配或排查异常。

## 具体怎么做
### 新增功能
1. 新增SearXNG搜索插件、钉钉与企微机器人webhook插件
2. 商业版支持API知识库、链接集合定时同步，钉钉SSO登录配置，飞书与语雀知识库导入，可点击查看对应教程
3. 猜你想问支持选择模型与自定义提示词
4. sandbox新增createHmac加密全局方法，工作流右键支持全部折叠
### 功能优化
1. 优化模型选择器、SSR渲染逻辑，新增移动端/PC端预判断以减少页面抖动
2. 优化工作流/简易模式变量初始化代码，移除监听初始化以避免渲染顺序导致的失败
3. 优化工作流数据类型不一致时的处理，增加类型转化以避免出现undefined
### 问题修复
1. 修复无法自动切换默认语言，新增分享链接强制执行默认语言切换
2. 修复数组选择器自动兼容4.8.13以前的数据，站点同步知识库时链接同步未使用选择器的问题
3. 修复简易模式转工作流未转换系统配置项、插件独立运行时变量初始值未赋值的问题
4. 修复工作流使用弹窗组件后关闭弹窗导致的页面偏移、插件调试日志未保存输入参数的问题
5. 修复部分模板市场模板异常，以及设置NEXT_PUBLIC_BASE_URL时图片文件读取URL不正确的问题
### 版本升级
两个版本均提供对应升级脚本，可在GitHub编辑页面获取。

## 注意事项
1. 部分新增功能仅商业版支持，需确认当前账号权限
2. 升级前需核对当前运行版本，避免跨版本升级出现异常
3. 数组选择器兼容修复仅针对4.8.13以前的旧数据
4. 配置NEXT_PUBLIC_BASE_URL时，需确认图片URL读取问题已完成修复
