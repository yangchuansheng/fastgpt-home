# FastGPT V4.8.1版本升级脚本操作指引

## 结论
FastGPT V4.8.1版本升级需通过官方配套的升级脚本完成，该升级方案属于FastGPT旧版本升级体系，仅面向版本低于4.12.0的用户，可完成从旧版本到V4.8.1的版本更新与配置适配。

## 具体怎么做
1. 确认当前FastGPT运行版本低于4.12.0，确认符合升级范围要求
2. 查找并获取官方发布的V4.8.1版本专属升级脚本
3. 按照脚本提供的操作指引，执行升级相关操作
4. 等待脚本完成升级流程，验证版本更新结果

## 注意事项
仅可使用V4.8.1对应的升级脚本完成升级，不可混用其他版本的升级脚本。该升级仅支持FastGPT版本低于4.12.0的场景，超出此范围的版本无法使用该脚本完成升级。升级操作需遵循官方文档的指引，避免因操作失误导致配置异常。
