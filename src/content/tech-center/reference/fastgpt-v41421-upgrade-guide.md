# FastGPT V4.14.21版本升级操作速查指南

## 结论
本页提供FastGPT V4.14.21版本的官方升级参考内容。该版本属于4.14.x系列升级分支，可通过官方对应流程完成合规升级。

## 具体怎么做
1. 进入FastGPT官方文档的4.14.x版本升级目录，定位到V4.14.21版本页面；
2. 核对当前部署的FastGPT版本所属分支，确认属于4.14.x系列；
3. 查阅对应版本的升级说明，若当前版本属于带有环境变量变更或升级脚本的分支，需按说明执行对应调整或脚本；
4. 按照官方指引完成V4.14.21版本的升级操作。

## 注意事项
1. V4.14.25版本已被弃用，请勿选择该版本进行升级；
2. 4.14.x系列中多个版本存在环境变量变更或升级脚本要求，包括V4.14.11、V4.14.10、V4.14.9、V4.14.8、V4.14.7、V4.14.5、V4.14.5.1、V4.14.4、V4.14.3、V4.14.1、V4.14.0等，升级前需提前核对；
3. 升级操作需严格遵循官方文档对应版本的指引，避免遗漏必要配置或脚本执行。
