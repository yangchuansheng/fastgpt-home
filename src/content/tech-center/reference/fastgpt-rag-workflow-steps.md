# FastGPT RAG流程的完整操作步骤说明

## 结论
FastGPT的RAG流程包含五个核心执行环节，可基于知识库生成符合需求的自然语言回答。该流程覆盖从查询输入到结果反馈优化的完整链路。

## 具体怎么做
1. 数据加载与查询输入：用户通过界面或API提交自然语言查询，系统接收后将查询传递至向量化器，利用BERT或Sentence Transformer等技术转换为向量表示。
2. 文档检索：向量化后的查询传入检索器，在知识库中查找最相关文档片段，可使用BM25或DPR等技术提升匹配效率与精度。
3. 生成器处理与自然语言生成：将检索到的文档片段作为输入，结合查询与文档内容生成回答，可使用GPT、BART或T5等模型，整合外部检索结果与预训练模型知识。
4. 结果输出：将生成的答案通过API或界面返回给用户，确保答案连贯且知识准确。
5. 反馈与优化：用户可对生成的答案进行反馈，系统通过微调模型参数或调整检索权重优化流程，逐步提升性能。

## 注意事项
- 文档检索可选择稀疏或密集检索技术，需根据实际场景确定适配方案。
- 生成器需基于检索到的文档片段与查询内容生成回答，不可脱离知识库独立生成。
- 用户反馈可用于调整模型参数与检索权重，需定期执行以持续优化流程。
