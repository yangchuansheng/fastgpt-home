# FastGPT 4.14.8及以上版本代码运行节点使用速查

## 结论
代码运行节点（sandbox v2）适配FastGPT 4.14.8及以上版本，可用于在工作流中执行自定义代码逻辑。该节点为工作流扩展提供灵活的自定义处理能力。

## 具体怎么做
1. 确保使用FastGPT 4.14.8及以上版本。
2. 进入应用构建的工作流编辑界面。
3. 在工作流的节点列表中添加代码运行节点。

## 注意事项
仅支持FastGPT 4.14.8及以上版本使用该节点。使用前需核对平台版本，避免出现兼容性问题。
