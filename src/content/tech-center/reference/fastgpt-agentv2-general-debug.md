# FastGPT AgentV2通用调试功能的使用说明

## 结论
FastGPT AgentV2的通用调试功能无需启用虚拟机即可使用，涵盖清空对话、查看运行详情等多种调试操作。这些功能可帮助开发者快速排查AI回复问题、审计交互成本与性能。

## 具体怎么做
1. 重开对话：点击调试窗口右上角的「重开对话」按钮，一键清空当前聊天历史。
2. 使用气泡操作栏功能：在每条AI回复的气泡下方，可调用以下辅助调试按钮：
   - 复制：一键复制该条AI回复的文本内容
   - 朗读：将该条回复文本转化为语音播放
   - 标注：对该条对话的问答数据进行标注并保存至指定知识库，可设置预期回答引导模型
   - 重试：让AI针对上一条用户输入重新生成回复
   - 运行详情：点击展开树状决策链路视图，查看本次交互的思考历程、内部参数、工具调用日志、请求Id、模型型号及积分消耗
   - 响应耗时：查看该次交互从发送请求到完全响应的耗时，格式如34.07 s
3. 查看步骤规划卡片：当AI面对复杂任务启动任务规划时，对话中会实时流式渲染计划步骤卡片（Plan Card），通过颜色区分执行节点状态。

## 注意事项
1. 通用调试功能无需启用虚拟机即可使用。
2. 使用标注功能需提前配置指定知识库，否则无法保存标注数据。
3. 步骤规划卡片的颜色状态包括进行中、已完成、待处理、已阻塞，遇到阻塞时可根据提示优化System Prompt或排查工具配置。
4. 运行详情中的积分消耗可用于性能审计与成本核算。
