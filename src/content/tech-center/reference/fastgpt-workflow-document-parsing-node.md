# FastGPT工作流节点文档解析组件的使用说明

## 结论
文档解析是FastGPT工作流中的内置节点组件，属于应用构建模块下工作流节点列表的功能项。开启文件上传功能后，即可使用该组件处理相关文档文件。

## 具体怎么做
1. 进入FastGPT的应用构建模块，打开对应的工作流编辑页面。
2. 在工作流的节点列表中，查找并找到文档解析节点。
3. 确认当前工作流已开启文件上传功能，即可添加该节点并完成使用配置。

## 注意事项
使用文档解析节点的必要前提是已开启文件上传功能，未开启该功能时，无法找到或正常使用该节点。该节点仅支持在FastGPT的工作流场景中使用。
