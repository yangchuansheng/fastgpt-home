# FastGPT V4.8.14版本升级操作速查说明

## 结论
FastGPT V4.8.14是FastGPT自部署的旧版本之一，归类在<4.12.0的升级分支范畴中。与部分相邻的低版本不同，该版本未标注需要单独调整的环境变量或专属升级脚本，升级流程无需额外处理特殊配置。

## 具体怎么做
1. 确认当前部署的FastGPT版本低于4.12.0，符合该升级分支的适用范围；
2. 访问FastGPT官方文档的自部署旧版本升级页面；
3. 在版本列表中找到V4.8.14条目，确认其未附带升级脚本或环境变量变更的标注；
4. 参考官方通用升级流程执行版本升级操作，无需额外配置专属参数；
5. 升级完成后，验证系统各项功能是否正常运行。

## 注意事项
1. 该升级说明仅适用于版本低于4.12.0的FastGPT自部署实例，不可用于更高版本的升级操作；
2. 升级前必须完成系统数据备份，防止因操作失误或中断导致数据丢失；
3. 若当前部署的版本带有环境变量变更或升级脚本标注，需参考对应版本的专属说明执行操作，不可直接套用V4.8.14的流程；
4. 升级过程中需确保服务器网络稳定，避免中断导致部署文件损坏或配置异常。
