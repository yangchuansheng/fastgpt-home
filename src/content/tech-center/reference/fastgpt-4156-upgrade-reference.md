# FastGPT V4.15.6版本升级操作参考指南

## 结论
本文档为FastGPT V4.15.6版本升级提供官方参考。该版本属于4.15.x系列升级分支，需遵循官方指定流程完成操作，部分前置版本存在环境变量变更或需执行升级脚本。

## 具体怎么做
1. 确认当前FastGPT版本属于4.15.x系列，优先从同系列版本发起升级。
2. 若当前版本为V4.15.0及更早的beta/正式版，需先执行对应升级脚本，并核对环境变量配置是否符合变更要求。
3. 按照官方提供的Docker Compose、Sealos或本地开发部署流程完成升级操作。
4. 升级前可查阅官方环境变量说明确认配置项，升级后可通过故障排查流程验证服务运行状态。

## 注意事项
1. 非4.15.x系列版本升级至V4.15.6前，需先适配前置版本的升级流程。
2. V4.15.0及以下版本升级时，需重点确认环境变量是否完成对应变更。
3. 升级过程中出现异常，可参考官方通用问题排查、模型问题排查或存储桶问题排查流程处理。
4. 升级操作需遵循官方部署文档的对应步骤，避免遗漏关键配置。
