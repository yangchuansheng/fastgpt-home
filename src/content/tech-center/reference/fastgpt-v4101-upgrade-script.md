# FastGPT V4.10.1版本升级脚本的使用操作说明

## 结论
FastGPT V4.10.1版本升级需使用专属升级脚本完成。该版本的升级流程属于低于4.12.0版本的升级分支，需遵循对应区间的升级规则。

## 具体怎么做
1. 确认当前FastGPT版本处于<4.12.0的区间内；
2. 查找并获取V4.10.1版本专属的升级脚本文件；
3. 按照官方升级流程执行该升级脚本，完成版本更新。

## 注意事项
1. 该升级脚本仅适用于V4.10.1版本的升级操作，不可用于其他FastGPT版本的升级；
2. 升级操作仅支持版本低于4.12.0的FastGPT实例，不适用于更高版本的升级；
3. 升级前可参考官方迁移备份相关文档完成数据备份，避免升级过程中出现数据丢失或异常。
