# FastGPT V4.14.28版本升级操作与配置说明

## 结论
V4.14.28是FastGPT 4.14.x系列的正式更新版本，面向自部署用户提供版本迭代支持。完成该版本升级需遵循官方指定的流程与配置要求，确保系统运行稳定。

## 具体怎么做
1. 确认当前FastGPT版本属于4.14.x系列，避免跨大版本升级
2. 访问对应版本升级页面，查阅V4.14.28的环境变量说明文档，确认配置要求
3. 若当前版本早于V4.14.11、V4.14.10等存在环境变量变更的子版本，先完成环境变量的更新调整
4. 根据自身使用的部署方式，选择Docker Compose部署、Sealos部署或本地开发对应的升级流程执行操作

## 注意事项
1. 仅支持4.14.x系列版本升级至V4.14.28，跨大版本升级需参考对应版本的官方文档
2. 部分前置4.14.x版本存在环境变量变更，未完成调整直接升级可能导致系统配置异常
3. 升级前建议完成系统数据与配置的备份，防止升级过程中出现数据丢失
4. 升级过程中若出现异常，可参考官方给出的故障排查文档
