# FastGPT V4.7版本升级脚本使用速查

## 结论
FastGPT V4.7版本升级需使用官方专属升级脚本，该流程仅面向版本低于4.12.0的FastGPT自部署实例。用户需通过官方指定渠道获取对应升级脚本，严格按照脚本指引完成操作，确保升级过程顺利。
## 具体怎么做
1. 确认当前FastGPT部署的版本号，确保其低于4.12.0
2. 从官方升级文档的对应板块，下载V4.7版本专属升级脚本
3. 运行获取到的升级脚本，按照提示完成版本升级操作
## 注意事项
1. 仅支持版本低于4.12.0的FastGPT实例升级，高于或等于4.12.0的版本需参考对应升级文档
2. 升级前需完成部署数据的备份操作，避免因升级导致数据丢失
3. 若升级至V4.7.1及后续版本，需同步检查环境变量变更内容
