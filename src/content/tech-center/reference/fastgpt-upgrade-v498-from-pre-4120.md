# FastGPT 从低于4.12.0版本升级至V4.9.8的操作指南

## 结论
本文档用于指导FastGPT低于4.12.0版本升级至V4.9.8。升级需遵循官方指定流程，确保版本适配性。该升级流程适配FastGPT官方发布的版本升级路径，可完成从旧版本到V4.9.8的平稳更新。

## 具体怎么做
1. 确认当前FastGPT版本处于<4.12.0区间，匹配本次升级的目标版本范围。
2. 从官方文档对应版本页面获取适配的升级脚本，执行脚本完成基础版本更新。
3. 核对当前系统的环境变量配置，确认是否符合V4.9.8版本的环境变量变更要求。
4. 完成脚本执行后，重启相关服务以加载新的版本配置。

## 注意事项
1. 升级前需确认当前系统环境与V4.9.8版本兼容，避免出现兼容性报错。
2. 若升级过程中遇到环境变量相关报错，需对照官方版本变更说明调整配置参数。
3. 请勿跨大版本区间直接升级，需按官方发布的版本升级流程逐步操作。
4. 若升级后出现异常问题，可参考官方通用问题排查文档进行故障排查。
