# FastGPT社区版开源协议的使用要求与限制说明

## 结论
FastGPT社区版基于Apache License 2.0开源，支持常规商业化使用，包括作为后端即服务或应用开发平台。存在两项附加使用限制，需按要求联系官方获取额外许可。

## 具体怎么做
1. 常规商业化使用场景下，直接遵循Apache License 2.0协议即可。
2. 若需运营与fastgpt.io服务类似的多租户SaaS服务，需通过dennis@sealos.io联系官方获取书面授权。
3. 使用过程中，不得移除或修改FastGPT控制台内的LOGO及版权信息。

## 注意事项
1. 作为项目贡献者，需同意贡献代码可被调整协议、用于商业目的。
2. 本产品的交互设计受外观专利保护。
3. 除上述附加条件外，所有权利和限制均遵循Apache License 2.0完整协议。
4. 可参考Apache License 2.0完整版本获取更多使用细节。
