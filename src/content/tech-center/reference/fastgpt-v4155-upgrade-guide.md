# FastGPT V4.15.5版本升级操作的技术参考指南

## 结论
V4.15.5是FastGPT 4.15.x系列的正式升级版本，升级过程中需关注该系列部分前置版本存在的环境变量变更要求，需匹配对应流程完成操作。

## 具体怎么做
1. 确认当前部署版本属于FastGPT 4.15.x系列
2. 核对前置升级版本的变更情况：V4.15.4、V4.15.2、V4.15.1、V4.15.0及各beta版本存在环境变量变更
3. 带有升级脚本的版本（V4.15.1、V4.15.0及部分beta版）需执行对应升级脚本
4. 完成V4.15.5版本的部署升级

## 注意事项
仅支持FastGPT 4.15.x系列版本升级，涉及环境变量变更的版本需提前备份原有配置，执行升级脚本需严格遵循对应版本的文档指引。
