# FastGPT V4.8.23版本升级脚本使用操作指南

## 结论
本页面针对FastGPT V4.8.23版本提供升级脚本相关操作指引。该版本属于<4.12.0的升级分支，需使用官方提供的专属升级脚本完成版本升级，是FastGPT自部署环境下的标准升级方式之一。

## 具体怎么做
1. 进入FastGPT官方文档的自部署升级页面，定位到<4.12.0分类下的V4.8.23版本模块。
2. 获取该版本对应的官方升级脚本文件。
3. 在已部署FastGPT的服务器中，按照脚本附带的指引执行升级操作。
4. 等待升级脚本执行完成，确认版本更新状态。

## 注意事项
1. 该升级脚本仅适用于FastGPT V4.8.23版本的升级操作，不可跨版本使用。
2. 该版本升级属于<4.12.0的升级范畴，需遵循该分类下的通用升级规则。
3. 升级操作需在FastGPT的自部署环境中进行，不适用于其他部署方式。
