# FastGPT V4.9.7版本升级操作与注意事项速查

## 结论
FastGPT V4.9.7版本升级适用于FastGPT版本低于4.12.0的自部署场景。该版本升级需遵循官方指定的升级流程，需关注对应版本的配置变更要求。

## 具体怎么做
1. 确认当前FastGPT版本低于4.12.0；
2. 对照官方版本升级列表，查看当前版本是否包含升级脚本或环境变量变更；
3. 执行对应升级脚本（若有），更新环境变量配置（若有变更）；
4. 完成V4.9.7版本的升级部署。

## 注意事项
1. 仅支持版本低于4.12.0的FastGPT部署升级至V4.9.7；
2. 升级前需确认当前版本对应的环境变量变更、升级脚本要求；
3. 需严格按照官方文档的升级流程操作，避免部署异常。
