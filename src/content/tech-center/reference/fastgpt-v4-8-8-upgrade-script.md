# FastGPT V4.8.8版本自部署升级脚本的使用说明

## 结论
本页内容针对FastGPT V4.8.8版本的升级脚本使用，该脚本是官方针对V4.8.8版本推出的专属更新工具，适用于版本低于4.12.0的自部署FastGPT用户，可通过该脚本完成版本更新。

## 具体怎么做
1. 确认当前部署的FastGPT版本低于4.12.0
2. 获取FastGPT官方提供的V4.8.8版本升级脚本
3. 按照脚本的指引执行操作，完成版本升级

## 注意事项
该升级脚本仅适用于FastGPT自部署场景，且当前部署的FastGPT版本必须低于4.12.0。需使用对应版本的专属升级脚本，不可与其他版本的升级脚本混用，避免出现升级异常。
