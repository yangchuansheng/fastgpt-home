# 介绍FastGPT商业版语雀文件库的导入配置与使用方法

## 结论
FastGPT v4.8.16及以上的商业版支持语雀文件库导入功能，该功能属于FastGPT第三方知识库的集成模块。用户可通过配置语雀的token与uid，完成语雀文档库的导入操作。

## 具体怎么做
1. 进入FastGPT知识库模块下的第三方知识库语雀文件库配置页面。
2. 在该页面中填入语雀的token与uid参数。
3. 保存配置后即可发起语雀文档库的导入流程。

## 注意事项
仅FastGPT v4.8.16及以上的商业版用户可使用该功能。当前功能处于测试阶段，存在部分待优化的交互环节。
