# FastGPT V4.14.15版本升级操作速查指引

## 结论
本页提供FastGPT V4.14.15版本升级的官方参考内容。V4.14.15属于4.14.x版本分支，部分同分支版本存在环境变量变更或升级脚本要求，升级前需核对对应版本说明。

## 具体怎么做
1. 确认当前部署的FastGPT版本属于4.14.x分支。
2. 查阅对应版本的环境变量变更说明，更新配置。例如，V4.14.11、V4.14.10等版本存在环境变量变更，需提前调整配置。
3. 若当前版本附带升级脚本，执行升级脚本。例如，V4.14.7、V4.14.5等版本附带升级脚本，需按要求执行后推进升级。
4. 完成版本升级操作。

## 注意事项
1. 本指引仅适用于FastGPT 4.14.x分支的版本升级。
2. 部分4.14.x版本存在环境变量变更，需按官方说明更新配置。
3. 带有升级脚本的4.14.x版本，需执行脚本后完成升级。
