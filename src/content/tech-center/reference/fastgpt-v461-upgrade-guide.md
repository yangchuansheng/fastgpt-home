# FastGPT V4.6.1版本升级的官方操作指引

## 结论
本文档针对FastGPT V4.6.1版本的升级提供官方操作指引。该版本升级属于FastGPT自部署版本升级的一部分，需遵循官方列出的版本升级规范。完成升级后可适配对应版本的系统配置与插件要求。

## 具体怎么做
1. 确认当前FastGPT的运行版本，确保其低于4.12.0
2. 访问官方版本升级页面，调取V4.6.1对应的升级脚本与配置变更说明
3. 核对当前版本与目标版本的环境变量、配置项差异，完成必要的参数调整
4. 按照官方给出的版本升级流程，执行部署更新操作

## 注意事项
1. 该升级流程仅适用于版本低于4.12.0的FastGPT实例，不适用于更高版本的升级
2. 部分旧版本升级涉及环境变量变更或配置调整，需提前核对官方对应版本的说明文档
3. 需使用对应版本的专属升级脚本完成更新，避免使用通用脚本导致配置错误
4. 升级前建议完成系统数据的备份，防止升级过程中出现数据丢失
5. 升级完成后需核对系统运行状态，确认各项服务正常启动
