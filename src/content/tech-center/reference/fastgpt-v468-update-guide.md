# FastGPT V4.6.8版本更新内容与使用说明

## 结论
本页整理FastGPT V4.6.8版本的官方更新内容，涵盖新增功能、优化项与问题修复。使用该版本可获得更灵活的模块配置与更流畅的交互体验。

## 具体怎么做
1.  使用新增的知识库搜索合并模块与新Http模块，新Http模块支持灵活参数传入，接口输出的JSON类型会自动转为字符串供其他模块使用，可参考官方文档查看示例。
2.  内容补全功能已内置至知识库搜索模块，一次补全即可完成指代消除与问题扩展。
3.  配置LLM模型时，无需再区分对话、分类、提取模型，可通过defaultConfig传入默认配置，避免不同模型参数冲突。
4.  流响应已优化，交互更丝滑，可修复部分乱码、中断问题。
5.  该版本修复了语音输入文件无法上传、对话框重新生成无法使用的问题。

## 注意事项
1.  升级至该版本需关注环境变量变更与升级脚本的相关要求，可参考V4.6.9版本的更新说明。
2.  新Http模块的自动类型转化仅支持接口输出JSON转字符串，其他类型转换需以官方文档示例为准。
3.  内容补全功能仅可在知识库搜索模块中使用，无法单独调用。
4.  流响应的优化效果可能因具体使用场景存在差异。
