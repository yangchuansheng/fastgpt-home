# FastGPT V4.14.30版本升级操作参考速查

## 结论
本页提供FastGPT 4.14.x系列版本升级的官方参考信息，涵盖V4.14.30及各子版本的变更说明。升级需结合对应版本的标记要求执行操作。

## 具体怎么做
1. 确认当前版本属于4.14.x系列，定位对应版本的升级说明文档
2. 若目标版本带有「环境变量变更」标记，需按照官方要求更新配置中的环境变量参数
3. 若目标版本带有「升级脚本」标记，需提前备份数据后执行对应升级脚本
4. 升级前可查阅通用问题排查、存储桶问题排查等文档排查潜在问题

## 注意事项
1. 本参考仅适用于FastGPT 4.14.x系列版本升级，不支持跨大版本直接升级
2. 带有「环境变量变更」标记的版本，需严格遵循官方说明更新参数，避免启动异常
3. 带有「升级脚本」标记的版本，必须在备份数据后执行脚本
4. 已弃用的V4.14.25版本不建议使用
5. 升级过程中可参考故障排查相关文档处理异常情况
