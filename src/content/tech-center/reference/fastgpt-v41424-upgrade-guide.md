# FastGPT V4.14.24版本升级操作速查

## 结论
本文档提供FastGPT V4.14.24版本升级的速查信息。该版本属于4.14.x系列升级分支，需结合对应版本的升级要求执行操作。
## 具体怎么做
1. 确认当前运行的FastGPT版本属于4.14.x系列。
2. 核对升级路径，避开已被弃用的V4.14.25版本。
3. 若升级涉及带有环境变量变更的版本（如V4.14.11、V4.14.10、V4.14.9、V4.14.8、V4.14.7、V4.14.5、V4.14.0等），提前调整对应环境变量配置。
4. 若升级涉及带有升级脚本的版本（如V4.14.7、V4.14.5.1、V4.14.5、V4.14.4、V4.14.3、V4.14.1、V4.14.0），执行对应升级脚本。
## 注意事项
1. 仅支持4.14.x系列内的版本升级，不宜跨大版本执行升级操作。
2. 涉及环境变量变更的版本升级前，需备份原有配置，防止启动异常。
3. 带有升级脚本的版本，需严格按照官方指引执行脚本，避免遗漏步骤。
