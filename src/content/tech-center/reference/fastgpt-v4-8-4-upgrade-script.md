# FastGPT V4.8.4版本升级脚本的使用说明

## 结论
FastGPT V4.8.4版本升级需使用官方提供的专用升级脚本完成。该版本属于<4.12.0版本区间的更新条目，升级操作依托专用脚本执行。
## 具体怎么做
1. 参考FastGPT官方文档的<4.12.0版本升级板块
2. 获取V4.8.4版本对应的官方升级脚本
3. 执行升级脚本完成版本更新
4. 如需保障数据安全，可参考官方迁移与备份指引完成数据保护
## 注意事项
- 仅可使用官方发布的V4.8.4升级脚本，避免使用非官方脚本
- 该升级流程仅适用于<4.12.0区间的FastGPT版本升级
- 升级前可根据需求完成数据迁移与备份操作
