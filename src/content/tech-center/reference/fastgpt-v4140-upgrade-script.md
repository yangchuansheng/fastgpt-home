# FastGPT V4.14.0版本升级脚本的操作说明

## 结论
FastGPT V4.14.0版本升级需使用官方配套的升级脚本完成。该版本属于4.14.x版本升级序列的基础版本，升级过程需留意对应子版本的环境变量变更提示。

## 具体怎么做
1. 访问FastGPT版本升级的4.14.x分类页面，定位到V4.14.0升级脚本相关文档
2. 下载并执行官方提供的V4.14.0配套升级脚本
3. 若从存在环境变量变更的子版本升级，需按对应版本指引调整环境变量配置

## 注意事项
1. 4.14.x序列中V4.14.25版本已被弃用，请勿使用该版本
2. 多个4.14.x子版本存在环境变量变更，升级前需查阅对应版本的官方说明
3. 升级操作需严格遵循官方文档的指引执行
