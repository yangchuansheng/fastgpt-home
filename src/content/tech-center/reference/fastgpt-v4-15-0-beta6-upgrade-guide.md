# FastGPT V4.15.0-beta6版本环境变量变更与升级操作指南

## 结论
FastGPT V4.15.0-beta6版本存在环境变量变更，需通过官方升级脚本完成部署更新。该版本属于4.15.x系列升级分支，需遵循官方指定的升级流程操作。

## 具体怎么做
1. 备份当前FastGPT部署的环境变量配置与业务数据，确保升级过程中数据安全。
2. 确认当前运行的FastGPT版本属于4.15.x系列前置版本，符合升级前提。
3. 执行官方提供的V4.15.0-beta6版本升级脚本，启动升级流程。
4. 根据官方发布的环境变量变更说明，调整对应配置参数。
5. 完成升级后，验证服务运行状态是否正常。

## 注意事项
1. 仅支持4.15.x系列版本的升级操作，不适用于其他版本分支。
2. 环境变量变更是该版本的核心更新内容，需严格按照官方说明调整配置。
3. 升级脚本是完成该版本升级的必要工具，请勿使用非官方脚本。
4. 升级过程中需确保操作环境稳定，避免异常中断引发问题。
