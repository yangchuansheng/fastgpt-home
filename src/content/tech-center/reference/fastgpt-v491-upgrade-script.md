# FastGPT V4.9.1版本升级脚本的使用说明

## 结论
FastGPT V4.9.1版本升级需使用专属升级脚本完成。该版本的升级操作属于<4.12.0版本区间的升级类型，需严格遵循对应流程执行。

## 具体怎么做
1. 确认当前FastGPT实例的版本低于4.12.0。
2. 获取V4.9.1版本对应的专属升级脚本。
3. 执行该升级脚本完成版本升级。

## 注意事项
1. 该升级仅适用于FastGPT V4.9.1版本的升级场景。
2. 需使用V4.9.1专属升级脚本，不得混用其他版本脚本。
3. 升级操作需在版本低于4.12.0的FastGPT实例上执行。
