# FastGPT V4.5.1版本的升级操作方法说明

## 结论
FastGPT V4.5.1版本升级需通过官方提供的专属升级脚本完成。该版本属于4.12.0之前的旧版本升级范畴，需遵循对应分类下的升级流程操作。

## 具体怎么做
1. 确认当前部署的FastGPT版本低于4.12.0，避免使用错误的升级脚本
2. 从官方渠道获取V4.5.1版本对应的专属升级脚本
3. 按照脚本附带的指引步骤，逐步执行升级操作

## 注意事项
仅支持版本低于4.12.0的FastGPT实例升级，不适用于更高版本的升级操作；必须使用V4.5.1对应的专属升级脚本，混用其他版本脚本可能导致升级失败；升级前建议完成数据备份，防止升级过程中出现数据丢失问题。
