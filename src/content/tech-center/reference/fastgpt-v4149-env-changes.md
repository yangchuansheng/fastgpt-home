# FastGPT V4.14.9版本环境变量变更的适配方法

## 结论
FastGPT V4.14.9版本存在环境变量变更，自部署用户升级或部署该版本时需调整对应配置项。本次变更属于版本升级的必要配置调整，仅涉及环境变量相关设置，不会影响FastGPT的核心业务功能运行。
## 具体怎么做
1. 进入FastGPT官方文档的4.14.x版本升级分类板块，定位到V4.14.9的专属升级说明页面。
2. 查阅页面内的环境变量变更详情，明确需要调整的具体配置项及修改规则。
3. 提前备份原有环境变量配置文件，避免修改过程中出现配置丢失或错误。
4. 根据官方说明完成对应环境变量的参数调整，保存配置后重启FastGPT服务。
## 注意事项
1. 本次环境变量变更仅适用于V4.14.9版本，其他4.14.x版本需查阅对应版本的升级说明。
2. 变更仅涉及环境变量配置，无需修改业务代码或核心部署脚本，操作难度较低。
3. 若重启服务后出现启动异常，可恢复备份的原有配置文件后重新尝试调整。
