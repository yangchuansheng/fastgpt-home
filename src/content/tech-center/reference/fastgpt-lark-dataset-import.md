# FastGPT商业版飞书知识库导入配置及使用方法

## 结论
FastGPT v4.8.16及以上版本的商业版用户，可配置飞书应用的appId与appSecret导入飞书知识库。该功能目前处于测试阶段，仅支持共享空间下的云文档导入。

## 具体怎么做
1. 准备飞书应用的appId与appSecret。
2. 在FastGPT中填入获取到的appId和appSecret。
3. 选择目标文档空间的顶层文件夹，完成导入。

## 注意事项
1. 仅支持商业版用户使用该功能。
2. 仅可获取共享空间下的文件目录内容，无法获取个人空间和知识库中的内容。
3. 目前仅支持导入云文档类型的内容。
4. 功能处于测试阶段，部分交互有待优化。
