# FastGPT V4.8.19版本更新内容技术速查

## 结论
本页汇总FastGPT V4.8.19的全部更新内容，涵盖新增功能、体验优化与问题修复三类，可帮助使用者快速查阅该版本的变更细节。

## 具体怎么做
1. 版本升级：使用官方提供的V4.8.19升级脚本完成部署更新。
2. 新增功能使用：
   - 支持通过JSON配置直接创建应用
   - 支持通过CURL脚本快速创建HTTP插件
   - 商业版用户可启用部门架构权限模式
   - 支持配置自定义跨域安全策略，默认全开
   - 补充私有部署与模型问题排查文档
3. 优化项与修复项升级后自动生效，无需额外配置。

## 注意事项
1. 自定义跨域安全策略默认全开，如需限制需手动配置。
2. 商业版部门架构权限模式仅对商业版用户开放。
3. 本次优化包含HTTP Body特殊处理（解决字符串变量带换行无法解析问题）、分享链接随机生成用户头像、图片上传安全校验、Mongo全文索引表分离、知识库检索语句合并减少查库数量、文件编码检测减少CSV乱码、异步读取文件减少进程阻塞、HTML文件直接下载不允许在线阅读等多项内容。
4. 修复了HTML文件上传base64图片无法自动转链接、插件计费错误两类问题。
5. 本次更新新增头像图片唯一存储功能，避免存储累积。
