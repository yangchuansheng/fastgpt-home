# FastGPT V4.15.2版本环境变量变更相关说明

## 结论
FastGPT V4.15.2版本存在环境变量变更，自部署用户升级至该版本时需调整对应配置。本次变更属于4.15.x系列版本升级的一部分，需严格遵循官方指引完成操作。

## 具体怎么做
1. 确认需升级至FastGPT V4.15.2版本。
2. 查阅本页面对应的V4.15.2环境变量变更说明。
3. 按照说明调整自部署环境的环境变量配置。

## 注意事项
1. 本变更仅适用于升级至V4.15.2版本的自部署场景。
2. 4.15.x系列的其他版本（如V4.15.1、V4.15.0等）也存在环境变量变更，需分别核对对应版本的说明。
3. 部分4.15.x低版本升级可使用官方提供的升级脚本完成配置迁移。
