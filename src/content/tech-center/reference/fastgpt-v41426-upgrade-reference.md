# FastGPT V4.14.26版本升级操作与注意事项速查

## 结论
本页提供FastGPT 4.14.x版本分支下V4.14.26版本的升级相关速查信息，涵盖该分支各版本的升级说明要点，可帮助技术人员快速确认升级注意事项。

## 具体怎么做
1. 进入FastGPT自部署的版本升级专区，找到4.14.x分支下的对应版本说明；
2. 查看版本说明后的标记，确认是否存在环境变量变更或需执行升级脚本；
3. 严格按照对应版本的官方升级指引完成操作。

## 注意事项
1. 仅支持4.14.x版本分支的升级，请勿直接跨大版本进行升级；
2. 带有（环境变量变更）或（升级脚本）标记的版本，需提前检查对应环境配置项或执行配套升级脚本；
3. 升级操作前，务必完成系统数据的备份工作。
