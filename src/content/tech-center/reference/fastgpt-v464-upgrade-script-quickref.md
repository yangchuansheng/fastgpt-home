# FastGPT V4.6.4版本升级脚本操作速查指南

## 结论
FastGPT V4.6.4版本升级需使用官方提供的专属升级脚本完成，该升级操作归类于<4.12.0版本升级的范畴。该专属脚本是FastGPT官方为V4.6.4版本推出的自动化更新工具，可完成从低版本到V4.6.4的部署更新。

## 具体怎么做
1. 确认当前FastGPT运行的版本低于4.12.0，满足升级的前置条件
2. 从官方文档的<4.12.0版本升级分类页面，获取V4.6.4版本的专属升级脚本
3. 按照脚本内置的操作指引，完成脚本的执行与必要的配置确认
4. 等待脚本自动完成版本升级的相关部署与更新操作

## 注意事项
1. 该升级流程仅适用于FastGPT版本低于4.12.0的实例，不适用于4.12.0及以上版本的升级
2. 必须使用V4.6.4专属升级脚本，混用其他版本的升级脚本可能引发部署异常
3. 升级过程需严格遵循脚本给出的操作提示，不可随意跳过必要的确认步骤
4. 升级完成后可通过官方文档提供的排查方式，确认系统运行状态正常
