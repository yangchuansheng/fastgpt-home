# FastGPT V4.14.29版本升级的操作说明

## 结论
本文档为FastGPT V4.14.29版本的升级说明，属于4.14.x分支的迭代更新。升级需结合当前版本匹配对应变更要求与流程。

## 具体怎么做
1. 确认当前运行的FastGPT版本属于4.14.x系列
2. 若升级至标注「环境变量变更」的版本，提前调整对应环境变量配置
3. 若升级至标注「升级脚本」的版本，执行官方提供的升级脚本
4. 完成V4.14.29版本的部署更新

## 注意事项
1. 仅支持4.14.x系列版本的升级，不可跨大版本直接升级
2. V4.14.25版本已弃用，请勿使用该版本
3. 升级前需备份原有配置与数据，避免丢失
4. 严格按照对应版本的标注要求执行操作，不可跳过前置步骤
