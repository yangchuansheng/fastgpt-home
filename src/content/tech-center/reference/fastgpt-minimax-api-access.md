# FastGPT环境下MiniMax大模型API的接入配置方法

## 结论
MiniMax是一家通用人工智能科技公司，提供高性能的大语言模型API服务。其API兼容OpenAI格式，可以便捷接入FastGPT平台。在开展MiniMax的接入配置前，请务必先阅读FastGPT官方的模型配置说明文档，确保掌握基础的配置逻辑与流程。
## 具体怎么做
1.  先完成FastGPT官方模型配置说明文档的阅读，全面了解FastGPT的模型接入通用规则与操作流程。
2.  借助MiniMax API兼容OpenAI格式的特性，按照FastGPT的通用模型接入方式，完成MiniMax的接入配置。
## 注意事项
1.  未阅读模型配置说明文档前，请勿开展MiniMax的接入配置操作，避免因不熟悉流程出现配置错误。
2.  仅支持使用兼容OpenAI格式的MiniMax API进行接入，非兼容格式的API无法直接接入FastGPT平台。
3.  配置过程需严格遵循FastGPT官方的统一配置规范，不得随意修改未明确的配置参数。
