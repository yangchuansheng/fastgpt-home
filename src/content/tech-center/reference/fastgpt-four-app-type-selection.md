# FastGPT四种应用类型的选型判断与使用参考

## 结论
FastGPT的四类应用类型按能力递进划分，可根据任务复杂度单独选择，也可组合使用。不同类型对应明确的适合场景与核心能力，能匹配不同的业务需求。

## 具体怎么做
首先按任务复杂度判断选型方向：
1. 轻量问答、文案生成、标准化输出：选择对话 Agent
2. 回答需基于资料、制度、法条、产品手册：选择知识库 + 对话 Agent
3. 流程固定且需条件分支、人工确认或自动化处理：选择工作流
4. 任务开放、步骤不固定，需自主分析、工具调用或代码执行：选择 Agent V2

各应用类型详情：
| 应用类型         | 适合场景                                   | 核心能力                                   |
|------------------|--------------------------------------------|--------------------------------------------|
| 对话 Agent       | 轻量问答、文案生成、标准化输出             | Prompt、模型配置、工具调用                 |
| 知识库 + 对话 Agent | 基于资料、制度、法条、产品手册的问答       | 文件导入、知识库检索、引用原文             |
| 工作流           | 固定步骤、条件分支、审核流、自动化处理     | 节点编排、判断器、人工确认                 |
| Agent V2         | 数据分析、复杂任务、多步推理、动态规划     | 自主规划、工具调用、虚拟机执行             |

组合使用示例：客服助手可使用知识库回答产品问题并调用工具查询订单；内容审核可通过工作流固定审核路径并结合知识库维护规则；数据分析可先用 Agent V2 完成探索，再将稳定步骤沉淀为工作流。

## 注意事项
工作流仅适配固定流程场景，无法处理开放的动态规划任务。Agent V2 需具备自主规划能力，不适用于流程固定的标准化任务。组合使用时需明确各模块的分工，避免功能重叠。
