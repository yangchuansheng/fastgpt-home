# 配置FastGPT智能数据分析Agent V2的具体操作步骤

FastGPT的对话Agent V2可用于搭建智能数据分析工具，支持读取用户上传的Excel/CSV文件、在隔离沙箱中运行Python分析代码，还能主动向用户澄清需求。该工具可完成数据概览分析、核心洞察提取、可视化图表生成与业务建议输出全流程。

## 具体配置步骤
1. 创建应用：在工作台点击新建应用，选择对话Agent V2，填写名称为智能数据分析Agent。
2. 配置模型与Prompt：选用GLM-5.1模型，系统提示词参考指定内容，包含角色定义、可用工具、工作流程、安全规则与输出格式。可用工具包括读取文件、沙箱执行、主动追问。工作流程需遵循先读取数据结构、制定分析计划、逐步执行、按需追问、输出完整报告的步骤。安全规则限定沙箱仅可做数据分析，禁止访问网络与写入宿主机文件，数据仅用于本次分析，不确定结论需标注置信度。
3. 配置开场白：设置引导用户上传文件并提出问题的话术，示例为"你好！我是智能数据分析Agent 📊 直接把Excel或CSV文件拖进来，告诉我你想分析什么。"并附带典型提问示例。
4. 开启虚拟机能力：启用虚拟机配置以隔离代码执行环境，支持运行数据分析脚本、读取上传文件与生成统计结果，且不会影响本地宿主环境。

上传销售数据示例文件，输入具体分析问题，例如"帮我分析这份销售数据，看看哪些产品卖得好，哪个渠道ROI最高"。Agent会先拆解任务，逐步执行分析，过程中可观察到任务在虚拟机中运行。测试时需重点确认Agent是否先识别表格字段、解释分析计划、按需运行代码、给出业务建议，若问题描述模糊，Agent应主动追问关键口径，不强行分析。
