# 使用FastGPT搭建并配置民法典知识库问答助手

该场景为知识库结合对话Agent的问答应用，可基于已有文档生成准确的针对性回答，区别于基础自由对话场景。用户可通过FastGPT的知识库管理与Agent配置功能，快速搭建面向特定文档的问答工具。

### 知识库创建与数据集配置
进入主页左侧知识库页面，点击右上角新建，填写知识库名称为"民法典问答助手"，保留其余默认配置。点击新建并选择文本数据集，用于导入本地文档。点击上传本地文件，选择示例文件，本案例仅上传单个文件。进入参数设置页，根据文件类型选择解析方式：上传PDF时建议开启解析设置，普通Word、Markdown、TXT等文件使用默认配置。处理方式选择分块存储，分块条件使用默认值。分块参数会影响问答质量，分块过大易引入无关内容，分块过小可能拆散关键上下文，快速上手可使用默认配置，正式接入企业文档可按需调整。纯文本场景勾选索引增强的前两个选项，含图片的文档可勾选图片相关增强。进入数据预览步骤，检查段落是否异常截断、标题与正文是否处于同一语义范围、表格条款编号是否可读。调整参数直至分块效果符合要求，等待数据状态变为"已就绪"。

### 对话Agent与问答配置
新建对话Agent，名称同样填写为"民法典问答助手"，在应用配置中关联已创建的民法典知识库。配置问答Prompt需明确基于知识库回答并引用原文，具体规则包括严格基于检索到的民法典条文回答、每条回答需引用编章节条号、无对应规定时如实说明、涉及案件适用时添加免责声明、对法律术语做通俗解释。输出格式包含法律结论、相关法条引用、通俗解读、实务建议、免责声明五个部分。配置开场白时，内置可一键提问的示例问题，如租房合同到期相关、网购售后相关、楼上漏水相关问题，并添加免责提示。验证问答效果时，测试资料内、资料外、模糊三类问题，确认回答包含法条引用、免责声明等要求内容。
