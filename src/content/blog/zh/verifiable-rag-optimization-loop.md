# FastGPT RAG 优化：建立可验证的检索与回答闭环

RAG 优化需要一组稳定的测试问题、可观察的检索证据和明确的评价标准。团队可以在 FastGPT 中把这些要素组成一个可重复的闭环，让每次参数、分块或模型调整都有清晰依据。

## 建立代表性问题集

从真实业务中选取高频问题、长尾问题和容易混淆的问题。每个问题同时记录期望引用的知识片段和回答要点，后续调整才能使用同一基准对比。

## 分开观察检索与回答

检索质量可以关注正确片段是否出现、排名是否合理、噪声片段是否过多。回答质量可以关注事实准确性、引用一致性和任务完成度。两类指标分开后，问题定位会更直接。

| 环节   | 观察对象     | 常用动作                 |
| ------ | ------------ | ------------------------ |
| 问题集 | 场景覆盖     | 补充高频与边界问题       |
| 检索   | 命中与排名   | 调整分块、索引和召回参数 |
| 回答   | 准确性与引用 | 调整提示词、模型和上下文 |
| 迭代   | 前后差异     | 保留基准和变更记录       |

## 一次只改变一个主要变量

每轮试验选择一个主要变量，使用同一问题集运行前后对比，并保留配置与结果。这样的迭代方式能够让改善来源可解释，也方便在结果波动时回到稳定基准。
