# Set up and use FastGPT Chat API

## Before you send a request

Confirm that the FastGPT application ID and API key are available in the target environment. Keep credentials outside logs and shared examples.

## Request flow

Send the request to the chat completions endpoint, include the application ID, and verify the streaming response before integrating it into your client.

## Verify the response

Check the response status and message content in a controlled environment. Record only the fields needed to troubleshoot an integration and keep customer data out of test payloads.
