# Publish a preview-gated editorial Blog

FastGPT will publish a Simplified Chinese Blog alongside the Technical Center and Guides, using versioned Markdown files and a registry. Each article has one primary category, either Product Updates or Technical Insights, while category filters use query parameters with `/blog` as the canonical URL. Blog routes remain exclusive to the Preview Host until approved articles are ready, preserving the existing content identities and the quality of the production search surface.
